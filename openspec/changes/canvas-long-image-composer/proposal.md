## Why

用户希望复用已经满意的主图和详情套图版本，轻量调整后组成长详情图，避免重新生成导致主体和文字变化。

## What Changes

- 画布新增「制作长图」，从当前项目图片及历史版本选图、拖动排序。
- 提供统一宽度、背景色、间距、逐图边缘裁剪和上下留白，实时预览，不拉伸主体。
- 服务端确定性拼接，保存项目资产并自动归档为详情成品，可下载完整 PNG 或按指定高度切片 ZIP。
- 保存所选资产版本及排版快照，可重新打开调整并另存；不覆盖来源图片，确定性排版拼接不调用生图模型。
- 增加选择性统一风格：仅处理勾选图片，支持参考图、风格提示词、自定义提示词三种方式，确认后生成候选版本，用户逐张采用后才替换长图中的对应项。

## Capabilities

### New Capabilities
- `canvas-long-image-composer`：项目图片版本选择、排版、拼接、保存归档与导出。

### Modified Capabilities
无。

## Impact

前端画布和 API 客户端；后端新增长图应用服务、图像排版器、路由与测试。复用 Pillow、项目资产来源快照、幂等请求记录和成品库，不新增依赖或数据库迁移。
