## Purpose

为单用户工作台提供可持久化、可发布且可回溯的生成配置，使后续生成始终能读取确定的市场、模型、风格和提示词版本。

## ADDED Requirements

### Requirement: 配置目录与工作区范围

系统 SHALL 在服务端按当前工作区保存生成配置目录。每个目录 SHALL 包含国内或国外范围下的具体电商平台、生图模型及其支持分辨率、风格大类与风格项，以及主图和详情页内置模块的提示词绑定。客户端不得指定或扩大工作区范围。每个风格大类 MUST 至多包含四个风格项，主图和详情页模块 MUST 保持内置且不得通过配置接口增删改。

#### Scenario: 初次读取默认配置
- **WHEN** 当前工作区从未保存过生成配置
- **THEN** 系统返回包含默认平台、模型、风格和内置模块的已发布配置

#### Scenario: 保存第五个风格被拒绝
- **WHEN** 草稿中的任一风格大类包含第五个风格项
- **THEN** 系统拒绝保存或发布该草稿，并返回稳定的配置校验错误

### Requirement: 草稿与发布生命周期

系统 SHALL 将编辑草稿与已发布配置分开保存。编辑草稿 MUST 不影响已发布配置；只有显式发布成功后，新的不可变配置版本才对后续工作台读取和生成快照解析生效。系统 MUST 支持放弃草稿并恢复到当前已发布配置。

#### Scenario: 未发布草稿不影响工作台
- **WHEN** 用户保存编辑草稿但尚未发布
- **THEN** 已发布配置读取和工作台选择器继续返回此前已发布版本

#### Scenario: 发布配置创建新版本
- **WHEN** 用户发布一个有效且与当前发布内容不同的草稿
- **THEN** 系统创建递增的已发布配置版本，并将其作为当前工作区后续使用的配置

#### Scenario: 放弃草稿
- **WHEN** 用户放弃当前草稿
- **THEN** 后续草稿读取返回当前已发布配置的内容，且已发布版本不变

### Requirement: 提示词具体版本绑定

系统 SHALL 允许市场、模型、风格、主图内置模块和详情页内置模块绑定提示词商城中的具体提示词版本。发布前，系统 MUST 验证每条绑定所引用的提示词模板与提示词版本存在且相互归属；绑定不得隐式解析或追随模板默认版本。

#### Scenario: 发布有效的提示词版本绑定
- **WHEN** 草稿绑定一个存在且属于指定模板的提示词版本
- **THEN** 发布后的配置保留该明确版本标识和用于展示的版本元数据

#### Scenario: 发布失效绑定被拒绝
- **WHEN** 草稿引用不存在的提示词版本，或该版本不属于声明的模板
- **THEN** 系统拒绝发布且不改变当前已发布配置

### Requirement: 已发布配置解析与历史可追溯性

系统 SHALL 提供当前已发布配置和指定历史已发布版本的受控读取，以及仅基于当前已发布版本的生成配置解析结果。删除或修改后续目录项不得修改既有已发布版本的内容；历史配置读取 MUST 不依赖当前目录反查。

#### Scenario: 删除目录项后读取历史版本
- **WHEN** 用户发布删除某个市场、模型或风格后的新版本
- **THEN** 此后当前配置不再提供该条目，但此前发布版本仍完整保留该条目及其绑定

#### Scenario: 工作台读取已发布配置
- **WHEN** 主图或详情页工作台请求可选市场、模型、风格和模块绑定
- **THEN** 系统只返回当前工作区的已发布配置，不返回未发布草稿

### Requirement: 配置 API 的一致错误与幂等

系统 SHALL 通过统一响应信封和请求 ID 暴露配置读写接口。创建草稿、替换草稿、发布和放弃草稿等副作用操作 MUST 支持幂等重试；相同幂等键但不同规范化请求载荷 MUST 返回稳定冲突错误。

#### Scenario: 重试发布不创建重复版本
- **WHEN** 客户端以相同幂等键和相同有效草稿重复提交发布请求
- **THEN** 系统返回首次发布的配置版本且不创建第二个已发布版本
