## Why

生成配置中心目前只存在于浏览器 localStorage。市场、模型、风格和提示词绑定在刷新、换设备或后端生成时都没有可靠的共同来源，无法成为阶段 3A 真实生图请求的可审计输入。

## What Changes

- 新增单用户、单工作区范围内的持久化生成配置域，保存市场、模型、风格分类与风格项、内置模块的提示词绑定。
- 为配置提供草稿、已发布版本、放弃草稿和版本递增接口；未发布修改不得影响工作台或后续生成。
- 保存绑定的具体提示词版本引用，并在发布时校验该版本仍可解析和使用。
- 将生成配置页面从浏览器持久化迁移到真实 API；主图和套图选择器读取已发布配置。
- 新增已发布配置解析接口，为后续任务保存不可变配置快照提供稳定边界；本变更不创建生成任务或调用图片 Provider。

## Capabilities

### New Capabilities

- `persistent-generation-config`: 服务端持久化生成目录、草稿/发布生命周期、提示词版本绑定和已发布配置解析。

### Modified Capabilities

- 无。

## Impact

- 后端新增 `generation_config` schema、迁移、配置仓储、应用服务和 `/api/generation-config` 路由。
- 前端新增生成配置 API 客户端，将 `useGenerationConfigStore` 改为只承载编辑态，页面和工作台从后端读取已发布配置。
- 复用现有提示词版本查询能力和项目身份/工作区边界；不修改项目素材、提示词商城或真实 Provider 接口。
