## Purpose

让主图工作台能够根据项目产品图、已发布生成配置和用户补充参数，先编译并确认图片专属提示词，再生成和保存一张真实主图，同时保留完整且可核验的生成来历。

## ADDED Requirements

### Requirement: 单张主图提示词编译请求
系统 SHALL 提供项目范围内的主图提示词编译请求。请求 MUST 只接受一个可用源图资产、一个已发布主图模块、一个具体电商平台、一个模型、一个风格、一个比例、一个分辨率和模块补充参数；该请求 MUST 不调用图片 Provider，而是创建待确认的单张主图任务。

#### Scenario: 有效选择创建待确认任务
- **WHEN** 用户提交属于当前项目的可用源图和当前已发布配置中的有效选择
- **THEN** 系统创建该请求的生成任务，完成视觉提示词编译并返回待确认任务

#### Scenario: 草稿或无效选择不能生成
- **WHEN** 请求引用未发布配置中的条目、未知条目、非本项目资产或非源图资产
- **THEN** 系统拒绝请求，且不得调用图片 Provider 或创建生成资产

#### Scenario: 单张限制保持生效
- **WHEN** 客户端尝试在请求中声明多张结果数量
- **THEN** 系统拒绝该请求或仅接受固定值一，且不会生成多张图片

### Requirement: 图像感知的待确认提示词
系统 SHALL 将源图、主图模块和用户补充参数交给多模态提示词编译模型，生成一份当前图片专属的待确认任务提示词。该任务提示词 MUST 基于可见内容和已确认参数；无法确认的信息 MUST 被标记且不得作为商品事实写入最终提示词。系统 MUST 在编译完成后展示任务提示词、可见事实、无法确认项和只读约束卡。

#### Scenario: 产品图参与提示词编译
- **WHEN** 主图提示词编译开始
- **THEN** 编译模型接收源图的视觉输入以及主图模块和补充参数，并返回任务专属提示词与可见事实摘要

#### Scenario: 编译结果不能伪造商品事实
- **WHEN** 产品参数缺失且图片无法可靠确认某个规格或卖点
- **THEN** 编译结果将该信息列为无法确认，且最终提示词不得把它表述为既定商品事实

### Requirement: 确认后才执行单张图生图
系统 SHALL 要求用户确认待确认任务后才调用图片 Provider。确认请求 MAY 修改实时任务提示词，但 MUST 不允许修改平台约束卡、全局风格约束卡、商品真实性约束卡、源图、已发布配置选择或结果数量；一次确认 MUST 只生成一张图片。

#### Scenario: 确认未编辑的待确认提示词
- **WHEN** 用户确认属于当前项目的待确认主图任务且不修改任务提示词
- **THEN** 系统以已编译任务提示词和冻结约束卡生成一张图片

#### Scenario: 编辑实时任务提示词后确认
- **WHEN** 用户只编辑待确认任务的实时任务提示词并确认
- **THEN** 系统保存原始编译提示词和确认后的任务提示词，并以确认后的任务提示词生成一张图片

#### Scenario: 未确认任务不调用图片 Provider
- **WHEN** 待确认任务尚未收到确认请求
- **THEN** 系统不得调用图片 Provider 或创建生成资产

### Requirement: 不可变平台和风格约束卡
系统 SHALL 从已发布配置中取得选定具体平台和风格的约束卡，并以原始内容、固定顺序加入最终生图提示词。提示词编译模型 MUST 不负责重写、删减或生成平台和全局风格约束卡。

#### Scenario: 平台与风格保持原文
- **WHEN** 用户选择已发布的淘宝规则和冷调精密风格
- **THEN** 最终提示词包含对应的原始平台约束卡与全局风格约束卡，任务提示词不能替换其内容

#### Scenario: 自定义风格影响当前任务而不修改全局卡
- **WHEN** 用户填写自定义风格
- **THEN** 该输入仅影响本次实时任务提示词与任务快照，已发布全局风格约束卡保持不变

### Requirement: 真实图生图执行与结果资产
系统 SHALL 使用源图文件和最终提示词调用配置的图生图 Provider；成功结果 MUST 校验为有效图片、写入项目对象存储并创建 `generated` 项目资产。项目生成结果 MUST 能通过既有受控预览接口读取。

#### Scenario: Provider 成功返回图片
- **WHEN** Provider 返回一张有效图片
- **THEN** 系统将图片持久化为当前项目的生成资产，并将该资产关联到源图和本次生成任务

#### Scenario: Provider 或输出失败
- **WHEN** Provider 超时、返回错误或返回无效图片
- **THEN** 任务进入失败状态，系统不创建生成资产，并返回不含密钥、授权头、内部存储凭据或完整上游响应的可读错误

### Requirement: 不可变生成快照与幂等结果
系统 SHALL 为每个主图生成任务保存不可变快照，包括源图版本与哈希、发布配置版本与哈希、平台/风格约束卡、主图模块、补充参数、提示词版本引用、原始编译结果、确认后的实时任务提示词、最终提示词哈希和非敏感 Provider 请求摘要。带相同幂等键且语义相同的重复编译或确认提交 MUST 返回同一任务，不得重复调用 Provider。

#### Scenario: 配置后续变更不影响历史结果
- **WHEN** 一张主图生成成功后，用户发布新的平台、风格或提示词配置
- **THEN** 历史任务和生成资产仍显示生成时保存的原始快照

#### Scenario: 相同幂等请求不重复扣费
- **WHEN** 客户端用相同幂等键重复发送同一主图生成请求
- **THEN** 系统返回首次任务，不创建第二个任务或第二次 Provider 调用

### Requirement: 主图工作台确认式真实状态展示
主图工作台 SHALL 以真实 API 代替本地模拟生成。用户发起提示词编译后 MUST 看到待确认提示词，且只能编辑实时任务提示词部分；用户确认后 MUST 看到生成中状态；成功后 MUST 看到真实结果；失败后 MUST 看到可读失败状态。完成后用户 MUST 能查看本次最终提示词与生成快照摘要。

#### Scenario: 编译、确认并成功生成
- **WHEN** 用户在主图工作台选择有效输入、确认服务端生成的提示词并点击确认生图
- **THEN** 页面依次显示待确认和进行中状态，完成后显示服务端返回的真实生成图片和最终提示词摘要

#### Scenario: 编译或确认生成失败
- **WHEN** 编译模型或确认后的图片 Provider 失败
- **THEN** 页面显示该任务失败原因，已有历史结果保持不变
