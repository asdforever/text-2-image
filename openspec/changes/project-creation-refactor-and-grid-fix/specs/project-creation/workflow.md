## Purpose

简化项目创建流程，移除无意义的输出目标选择步骤。

## MODIFIED Requirements

### Requirement: 项目创建流程
系统 SHALL 提供简化的项目创建流程，只需要项目名称和产品名称两个必填字段。

#### Scenario: 创建新项目
- **WHEN** 用户打开项目创建对话框
- **THEN** 系统显示项目名称和产品名称输入框
- **THEN** 系统不显示输出目标选择步骤

#### Scenario: 提交项目创建表单
- **WHEN** 用户填写项目名称和产品名称后点击创建
- **THEN** 系统创建项目并包含所有工作区能力（白底图、套图、视频）
- **THEN** 用户无需选择输出目标

#### Scenario: 访问新创建的项目
- **WHEN** 用户进入新创建的项目工作台
- **THEN** 系统显示所有工作区标签页（白底图、套图、视频）
- **THEN** 所有标签页均可访问，不受创建时选择限制

## REMOVED Requirements

### Requirement: 输出目标选择
**Reason**: 该选择步骤无实际作用，工作台始终显示所有标签页，使得选择变得毫无意义
**Migration**: 移除 `outputTargets` 字段和相关的选择界面，所有项目默认获得全部工作区能力
