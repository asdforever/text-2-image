## Purpose

为白底图工作区提供一致的原图输入流程，使用户既能提交本地图片，也能复用图片素材库中的已有素材，并在输入来源不可用时继续完成可用操作。

## ADDED Requirements

### Requirement: 白底图工作区提供两种原图输入来源

系统 SHALL 在白底图工作区同时提供“提交素材”和“从素材库选择”两个独立入口，二者加入的图片均作为当前项目的原图参与白底图生成。

#### Scenario: 提交本地原图
- **WHEN** 用户点击“提交素材”并选择符合现有校验规则的本地图片
- **THEN** 系统将图片加入当前项目的原图列表，并允许用户对其生成白底图

#### Scenario: 打开素材库选择器
- **WHEN** 用户点击“从素材库选择”
- **THEN** 系统打开素材库选择器，且不影响已经加入当前项目的原图

### Requirement: 素材库选择器仅提供图片素材

系统 SHALL 仅展示图片类型素材库及其中可用的图片素材，不得将文本素材作为白底图输入候选项。

#### Scenario: 展示图片素材库
- **WHEN** 素材库同时包含图片库和文本库
- **THEN** 选择器仅列出图片库，并在用户选择图片库后展示该库的图片素材

#### Scenario: 图片素材库为空
- **WHEN** 用户选择的图片素材库不包含图片
- **THEN** 选择器显示空状态，并保持“确认添加”不可用

### Requirement: 用户可批量选择素材库原图

系统 SHALL 允许用户在选择器中选择一张或多张图片，并在确认前清楚显示当前选择状态。

#### Scenario: 多选素材并确认
- **WHEN** 用户选择多张图片素材并点击“确认添加”
- **THEN** 系统将所有未重复的已选素材加入当前项目原图列表，关闭选择器，并反馈实际新增数量

#### Scenario: 取消素材选择
- **WHEN** 用户在选择器中调整选择后点击“取消”或关闭对话框
- **THEN** 系统不向当前项目添加任何素材

### Requirement: 素材库原图保留来源并避免重复加入

系统 SHALL 使用素材库及素材的稳定标识记录来源，并阻止同一素材被重复加入同一个项目。

#### Scenario: 首次加入素材库原图
- **WHEN** 用户确认添加一个当前项目尚未引用的图片素材
- **THEN** 系统创建可用于白底图生成的项目原图，并保留其素材库 ID 和素材 ID

#### Scenario: 再次选择已加入的素材
- **WHEN** 用户选择已存在于当前项目的同一素材库图片
- **THEN** 系统不创建重复原图，并反馈该素材已存在或实际新增数量为零

#### Scenario: 一批选择包含新增和重复素材
- **WHEN** 用户确认的一批素材同时包含已加入素材和新素材
- **THEN** 系统仅加入新素材，并反馈新增数量和跳过的重复数量

### Requirement: 素材库故障不阻塞本地提交

系统 SHALL 为素材库加载过程、加载失败和无可用图片提供明确状态，并在这些状态下保持本地提交入口可用。

#### Scenario: 素材库正在加载
- **WHEN** 系统正在读取素材库或所选库的素材
- **THEN** 选择器显示加载状态并防止重复提交选择请求

#### Scenario: 素材库加载失败
- **WHEN** 素材库接口因数据库或网络问题返回失败
- **THEN** 选择器显示可重试的错误状态，用户关闭选择器后仍可提交本地原图

#### Scenario: 没有图片素材库
- **WHEN** 系统未返回任何图片类型素材库
- **THEN** 选择器显示“暂无图片素材库”的空状态，并保持本地提交入口可用
