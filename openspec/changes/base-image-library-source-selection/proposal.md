## Why

白底图工作区当前只能从本地提交原图，已经沉淀在全局图片素材库中的素材无法复用，用户需要重复下载和上传。数据库暂时不可用，但输入来源的交互与前端契约可以先完成，并在数据库恢复后补充真实联调。

## What Changes

- 保留白底图工作区现有的本地图片提交入口。
- 新增“从素材库选择”入口，仅展示图片类型素材库及其中的图片素材。
- 支持从素材库多选原图，并将确认选择的素材加入当前项目的白底图输入列表。
- 记录素材库来源标识并阻止同一素材被重复加入当前项目。
- 为素材库不可用、加载失败、空库和无有效图片提供明确状态，并允许用户继续使用本地提交。
- 先使用 mock API 和自动化测试验证前端流程；数据库恢复后再执行真实接口联调。
- 本次不包含将生成后的白底图或套图发布、归档或同步回素材库。

## Capabilities

### New Capabilities

- `base-image-input-sources`: 定义白底图工作区通过本地提交或图片素材库选择原图，以及素材导入、去重和异常状态的行为。

### Modified Capabilities

无。

## Impact

- 前端白底图工作区及其输入来源选择对话框。
- 项目资产类型与 Zustand 持久化数据，需要保存可选的素材库来源信息。
- 现有素材库读取客户端 `listAssetLibraries`、`listAssets`，不新增写入素材库的 API。
- 白底图工作区和项目资产 store 的单元/交互测试；真实数据库与 MinIO 联调延后执行。
