## Purpose

让用户先用最少的项目基础信息完成项目创建，再进入工作台提交素材，避免把素材准备与项目身份建立绑定在同一个步骤中。

## ADDED Requirements

### Requirement: 创建项目流程不包含素材上传步骤

系统 SHALL 在新建项目流程中移除上传素材页面，用户只需选择产物并填写有效的项目名称和商品名称即可继续。

#### Scenario: 无素材创建项目
- **WHEN** 用户未提交素材并填写有效项目资料后点击创建
- **THEN** 系统创建空素材项目并进入该项目工作台

### Requirement: 基础项目资料校验

系统 SHALL 在项目名称或商品名称为空时阻止创建，并显示对应的校验提示。

#### Scenario: 缺少项目名称
- **WHEN** 用户未填写项目名称并点击创建
- **THEN** 系统显示校验提示，不创建项目
