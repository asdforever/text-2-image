## Why

当前新建项目对话框仍包含上传素材步骤，虽然素材已经可以跳过，但这一步仍增加了创建成本。应用的左侧导航也只服务于工作台内部工具，项目管理和提示词资源缺少稳定的全局入口，异步生成任务的状态更难集中查看。

## What Changes

- 移除新建项目流程中的“上传素材”步骤，创建时只填写项目资料并选择产物，素材继续在项目工作台内提交。
- 建立跨页面统一的左侧主导航，提供工作台、项目管理、提示词商城和任务中心四个分支。
- 将当前欢迎页的最近项目能力整理为项目管理入口，支持创建、进入和维护项目。
- 将现有风格库中的提示词模板能力调整为提示词商城定位，支持浏览、搜索、查看详情、复制和应用模板。
- 新增任务中心页面，集中展示生成中、已完成和失败可重试的任务状态。
- 统一主导航下的页面标题、激活态、返回行为和窄窗口布局。

## Capabilities

### New Capabilities

- `global-navigation`: 跨页面主导航、分支激活态和导航布局。
- `project-creation-flow`: 精简的新建项目流程和基础信息校验。
- `project-management`: 项目列表、创建入口和项目维护工作流。
- `prompt-marketplace`: 提示词模板的浏览、详情、复制和应用入口。
- `task-center`: 异步生成任务的集中状态查看和失败重试。

## Impact

- 路由：扩展 `src/routes/router.tsx`，为主导航分支提供稳定 URL 和页面入口。
- 页面：调整 `WelcomePage`、`ProjectCreateDialog`、`ProjectWorkbench`，新增项目管理、提示词商城和任务中心页面或容器。
- 导航与样式：新增全局侧栏、页面激活态、响应式约束，并复用现有亮暗主题 token。
- 数据：项目管理复用 `useProjectStore`；提示词商城和任务中心复用现有 API client 与资源/任务模型。
- 兼容性：保留现有项目工作台内部白底图、套图和视频 tab，不改变项目内素材归属规则。
