## Why

提示词商城目前只能按执行类型（图生图、文生图等）分组，随着提示词数量和业务场景增加，用户很难按商品阶段、用途或团队约定快速定位模板。需要增加独立于执行类型的自定义业务分类，并让分类管理贯穿新建、编辑、筛选和删除流程。

## What Changes

- 新增可持久化的提示词分类实体，分类包含稳定 ID、名称、排序和创建/更新时间。
- 提示词模板支持关联一个业务分类，同时保留现有执行类型字段和分组行为。
- 提示词商城侧栏增加分类筛选与分类数量统计，支持“全部、未分类”和自定义分类视图。
- 新增分类管理入口，支持新增、重命名和删除分类；删除分类前展示受影响模板数量，确认后模板转为“未分类”。
- 新建提示词和编辑模板信息时支持选择或新建分类；未选择分类时归入“未分类”。
- 搜索结果与批量操作遵循当前分类筛选范围，空分类和无结果状态提供明确反馈。
- 为 API、数据库模型、前端交互和分类边界补充测试与迁移。

## Capabilities

### New Capabilities

- `prompt-marketplace/custom-categories`: 管理提示词业务分类、将模板归类并按分类浏览。

### Modified Capabilities

- 无

## Impact

- 后端 `PromptTemplate` 数据模型、仓储、服务和提示词路由；新增分类表/字段及迁移。
- 前端 `PromptMarketplacePageNew`、`PromptSidebar`、`PromptCard`、新建/编辑表单和 API client 类型。
- 需要处理旧模板兼容：现有记录没有分类时显示为“未分类”，不影响原有按执行类型筛选。
- 新增分类相关单元测试、接口契约测试和商城端到端交互测试。
