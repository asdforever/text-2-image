## 阅读顺序

先看学习版的项目定位和整体架构，再沿着“整体规划 → 单图编译 → 确认 → Worker 执行 → 资产归档”读代码。需要改动提示词、反推绑定或图像编辑时，对照深度版确认生效时机与边界。面试前阅读面试版，并用自己的实际负责范围替换其中的个人表述。

## 文档维护

- 后端仓库为 `text-2-image`，前端仓库为同级的 `text-2-image-front`，两者独立管理 Git。
- 这里记录当前实现；`openspec/`、历史交付报告和研究资料用于追溯设计，不能单独作为现状依据。
- 修改规划协议、最终提示词、任务状态、模型连接、部署方式时，同步更新学习版及面试版对应章节。
- 修改提示词商城绑定、反推材料链路、图像编辑流程，或修复/新增已知问题时，同步更新深度版的对应小节。
- 深度版中标注“未定位 / 待核实”的条目属于排查中间结论，不能当作已确认事实引用。
- 版本表记录的是依赖声明范围，不能据此推断本机实际安装版本。
- 当前文档经过源码与链接核对，未以这次文档整理验证真实模型效果或服务器部署。

前后端快速入口：[后端 README](../../README.md)、[前端 README](../../../text-2-image-front/README.md)。跨仓库相对链接要求两个仓库保持同级目录；单独浏览后端仓库时，前端链接可能不可用。
