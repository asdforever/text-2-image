## 当前结论

阶段 3A 的本地实现和自动化验证已完成。主图工作台现在以一个项目源图、一个主图模块和一张结果为边界：先由多模态模型读取源图并编译实时任务提示词，用户检查或编辑该任务段后确认，服务端才调用图片编辑 Provider。成功图片写入对象存储并创建项目生成资产。

## 已实现能力

- `compiling_prompt -> awaiting_confirmation -> generating -> succeeded | failed` 的主图生成任务生命周期。
- 多模态提示词编译模型读取项目源图、主图模块、模块补充参数和自定义风格，返回实时任务提示词、可见事实和无法确认项。
- 商品真实性、具体电商平台、全局风格三张只读约束卡由服务端从已发布配置解析，编译模型和浏览器都不能改写。
- 最终提示词固定按“真实性约束、平台约束、风格约束、已确认实时任务提示词”组合。
- 用户必须确认后才调用 `/v1/images/edits`；请求以 multipart 上传源图，固定 `n=1`，服务端映射比例、分辨率和 Provider 参数。
- 编译与确认分别使用幂等键；重复请求不会重复编译或重复调用计费 Provider。
- 浏览器保存当前任务 ID 和两条幂等键；刷新或网络结果未知时会读取任务接口恢复待确认、生成、成功或失败状态，重试沿用原键。
- 任务保存源图哈希、发布配置版本与哈希、提示词版本、约束卡、编译结果、最终提示词及非敏感 Provider 请求摘要。
- 成功结果校验后写入对象存储并创建 `generated` 项目资产；对象或数据库失败时执行补偿，失败任务不覆盖已有历史结果。
- 项目资产保留生成任务 ID；历史主图卡通过任务快照展示生成时的模块、模型、比例、分辨率和风格，不回退为当前草稿。
- 主图工作台展示编译中、待确认、生成中、成功和失败状态；成功后保留最终提示词哈希与快照摘要。

## HTTP 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/projects/{projectId}/hero-generations/compile` | 读取已发布配置和源图，编译待确认提示词，不调用图片 Provider |
| `GET` | `/api/projects/{projectId}/hero-generations/{taskId}` | 读取任务状态、只读约束和安全快照摘要 |
| `POST` | `/api/projects/{projectId}/hero-generations/{taskId}/confirm` | 确认或编辑实时任务提示词，并生成一张主图 |

## 真实验收环境变量

以下值只写入本机 `.env` 或部署环境，不提交真实密钥：

| 变量 | 用途 |
| --- | --- |
| `CONTEXT_BASE_URL` | OpenAI 兼容多模态服务地址 |
| `CONTEXT_API_KEY` | 多模态提示词编译服务密钥 |
| `CONTEXT_MODEL` | 支持图片输入的多模态模型名 |
| `CONTEXT_TIMEOUT_MS` | 多模态请求超时，默认 `600000` |
| `IMAGE_GENERATION_BASE_URL` | OpenAI 兼容图片服务地址 |
| `IMAGE_GENERATION_API_KEY` | 图片生成服务密钥 |
| `IMAGE_GENERATION_MODEL` | 图片编辑模型名，默认 `gpt-image-2` |
| `IMAGE_GENERATION_TIMEOUT_MS` | 图片请求超时，默认 `600000` |

同时必须配置阶段 1 所需的 PostgreSQL 和 MinIO/S3 连接，并确保数据库已前向迁移到当前 Alembic head、生成配置已有可用的已发布版本。浏览器通过 `VITE_FASTAPI_PROXY_TARGET` 访问 FastAPI，默认是 `http://127.0.0.1:8000`。

## 真实 Provider 前端验收步骤

1. 在项目根目录配置 `.env`，确认上述多模态、图片生成、PostgreSQL 和对象存储变量完整；不要在截图、日志或问题反馈中粘贴密钥。
2. 执行 `python -m backend.cli migrate`，只做前向迁移；业务数据库不得执行 downgrade。
3. 执行 `npm run api` 启动 FastAPI，再访问 `GET /api/ready`，确认数据库、schema、对象存储、项目域、生成配置和主图生成依赖均就绪。
4. 执行 `npm run dev -- --host 127.0.0.1 --port 5173`，打开一个已有源图的项目并进入“主图”工作台。
5. 只选择一张产品源图、一个具体电商平台、一个图片风格、一个主图模块，以及受当前模型支持的比例和分辨率；按需填写模块补充参数。
6. 点击“编译提示词”，确认页面出现三张只读约束卡、可见事实、无法确认项和唯一可编辑的“实时任务提示词”；此时不应产生图片 Provider 请求或生成资产。
7. 检查实时任务提示词没有把无法确认项写成商品事实，必要时只编辑该任务段，然后点击“确认并生成”。这一步会发起一次真实、可能计费的图片请求。
8. 成功时确认页面展示一张真实结果、“本次生成快照”、最终提示词哈希和最终提示词；刷新项目后生成资产仍可从受控预览接口读取。
9. 使用无效测试密钥或受控失败环境验收失败路径：页面应显示可读错误，响应和任务记录中不得出现密钥、授权头或完整上游响应，已有历史主图必须保留。
