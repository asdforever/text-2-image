# 规划大师：使用与验证

## 使用

1. 打开项目的主图或详情套图，选择产品素材，粘贴商品资料。
2. 点击「自动规划」，自动选择每张图的模块、分配参数并输出「建议构图简案」。也可直接点击「编译提示词」，系统会先完成尚未完成或已过期的规划。
3. 检查规划摘要、待核实事项及各模块参数，需要时手动修改。
4. 编译模块提示词，确认后再生成图片。
5. 在画布「制作长图」中查看最近的主图/详情规划顺序建议，自行选图、排序和拼接。生成配置和提示词确认区不再提供排序按钮；图片编号只用于识别条目。读取建议仅发 GET，请求失败或建议迟到不会修改已有拼接排版。

规划大师是后端内置能力，不提供选择、绑定或编辑入口。后端根据 `mode=hero|suite` 自动读取 `backend/app/skills/hero-planning-master/SKILL.md` 或 `backend/app/skills/suite-planning-master/SKILL.md`。这两份 Skill 由开发者维护并随应用部署，仍沿用现有提示词模型连接执行。

后端每次新规划读取对应 Skill，把完整内容作为模型系统指令，产品资料、模块目录和平台约束作为本次输入；无需用户配置 Skill。调用前记录 Skill 名称、内容哈希和完整指令，便于追溯。缺失或无法读取时明确报错，不回退到旧商城绑定；旧配置中的 `plannerBindings` 在新配置保存/发布时忽略，历史任务快照保持原样。

## 职责与调用次数

规划大师负责模块选择、信息顺序、各模块参数和构图简案。共享风格规划器负责配色、光影、背景和字体等视觉语言。每个模块的编译器根据分配到的简案及共享风格细化自己的生图提示词。

首次自动规划并编译 N 个模块，通常调用大语言模型 N + 2 次：规划大师 1 次、共享风格规划 1 次、模块编译 N 次。已经完成且输入未变化的规划直接复用。图片生成另行确认，不包含在上述调用中。

详情套图不再限制 5 个模块，可使用当前已发布的完整模块目录；同一模块可用于多个独立图片任务。主图最多 8 个图片任务。

每个规划条目对应一张图，两个 Skill 的 `resultCount` 固定为 1，后端校验该约束。前端移除了复制任务和张数选择；旧草稿和旧规划回填时每项按 1 张处理，重新编译固定提交 1 张。需要更多内容时添加独立条目，各自有 `taskId`、参数和构图。已提交批次仍按原始数量恢复、确认和展示进度。

## 恢复与重试

- 切换页面、退出项目再进入或刷新时读取已有规划，不自动新增模型调用。
- 资料、素材、平台、比例或语言变化后，不应用旧请求的迟到结果；编译前按新输入规划。
- 重新规划时更新未手改的自动参数，保留真正的人工修改；刷新同一规划保留最终模块选择和参数。
- 网络失败保留幂等键，避免重复请求模型；已知终态失败允许发起新规划。
- 规划原文、结果与调用前的配置、Skill、素材和连接快照保存在数据库；编译任务记录其规划来源。进程中断留下的规划在超过 10 分钟后显示失败，允许重新规划。
