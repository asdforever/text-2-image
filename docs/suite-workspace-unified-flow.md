# 详情套图与主图流程统一

更新时间：2026-09-19。

本次按用户确认的方案调整详情套图工作台，接续已有 `suite-planning-and-generation` 能力，不重建生成链路。

## 页面与交互

- 左侧保留素材、平台、风格、模块张数和参数、输出设置；按钮为“生成套图提示词”。
- 右侧直接展示每个模块的提示词、张数和排序按钮；平台、风格、商品约束保持完整，默认折叠。
- 标题、文案摘要、画面说明及视觉分析作为只读规划依据；用户直接编辑任务提示词。
- 底部固定“确认并生成 N 张”。移动端编译完成后收起配置，确认按钮始终在结果区底部。
- 提示词草稿按项目和规划标识保存在当前浏览器；模块排序不覆盖草稿。确认直接提交当前内容，不依赖失焦保存。
- 相同规划和提示词重试确认时复用幂等键，跨刷新保留；提交失败保留输入。
- 确认后原位显示逐张进度、失败原因和单张重试；保留图片预览、下载、整套导出及已确认提示词。
- 本批次配置使用后端快照，左侧后续修改不会改变已确认任务。
- 主图和套图共用批次进度组件及执行器状态提示。长图拼接与画布版本操作保持现有入口。

## 执行器状态

新增迁移 `f7a8b9c0d1e2`，建立 `project_workbench.generation_worker_heartbeats`。本机已执行迁移。

`generation-worker` 每 10 秒更新自身心跳，长时间生图时继续更新；45 秒未更新判为离线。实例正常退出时仅清理自身记录，异常退出依赖过期判断。

`GET /api/generation-worker/status` 返回 `online`、`offline` 或 `unknown`。数据库检查失败时返回未知，不冒充在线或离线。Vite 已将该接口代理至 FastAPI。

排队时前端每 10 秒查询状态；离线提示任务仍保留，无需重复确认。心跳代表执行进程存活，不代表第三方图片服务一定可用。

启动仍使用 `npm run api`，同时运行接口和执行器。
