# V2 统一模块规划

## 已确认的行为

新任务保留图片风格选择和规划大师。每种内置风格提供一段简短、固定的基础提示词，作为所有图片任务的共同输入。每个图片任务的一次模块规划调用同时完成风格细化、构图和内容规划，不再先单独调用风格规划模型。

规划大师仍负责自动分配模块。模块可重复使用，但各图片任务使用独立 taskId 和参数。各模块规划需要知道整套任务大纲，避免重复表达同一内容。风格细化应在选中风格范围内调整明暗、光线和信息密度，不应重新发明视觉方向。

最终生图提示词由服务端组装：商品真实性、平台约束、基础风格、模块风格细化、构图及内容规划、输出规格。用户选择的比例、分辨率和语言由系统注入。模型返回结构化规划，不能直接返回一个自由拼接的最终 taskPrompt。

图片中仍可生成文案；这次改动不强制将所有文字迁移到画布叠字。

## 确认与修改

V2 确认页显示服务端生成的提示词，只读且可以复制。如需调整，修改左侧模块参数后重新编译。浏览器遗留的提示词草稿不会覆盖 V2 结果，确认重试复用同一个幂等键。

已清理 V1 任务；所有新任务与恢复任务只使用 V2 冻结快照。项目与素材由用户自行删除。

## 版本与快照

API 的任务、批次、套图规划资源返回可选的 `plannerVersion`，新任务为 `v2`。版本由服务端决定，不增加普通用户版本选择器。

新快照保存固定风格种子的身份、正文和哈希，以及模型连接、结构化规划结果、渲染器和最终组装器版本。渲染后的提示词正文也保存并校验哈希，未来更新渲染器时仍能恢复原提示词。提示词商城中的旧风格规划模板已移除，风格由固定种子和每次模块规划共同确定。

维护提示词组装逻辑时，需保留已发布版本的组装函数。确认流程按快照中的 `composerVersion` 选择实现；未知版本直接报错，避免悄悄使用新规则改变历史任务。
