# 生图模型连接配置实施计划

**目标：** 模型配置管理接口地址、API Key、实际模型名与能力；新生成请求实际使用所选模型，移除模型提示词绑定。

**架构：** 模型目录引用不可变连接版本 `connectionId`。连接表按工作区隔离，Key 单独加密；普通配置和生成快照仅保留无密钥连接信息。已有 `.env` 连接作为旧配置兼容来源，新增配置通过保存草稿、发布生效。已提交任务保留连接版本。所有界面、错误及文档中文，保留工作区其他修改，不提交 Git，不调用真实付费模型。

## 接口约定

- `GET /api/model-connections`：返回连接数组，字段 `id,baseUrl,modelName,protocol,hasApiKey,createdAt`；永远不返回 Key。
- `POST /api/model-connections`：`{baseUrl,modelName,protocol:"openai_images",apiKey?,reuseConnectionId?}`。新连接必填 Key；修改留空时从已有连接或 `environment` 复用 Key。每次保存创建新连接版本，返回上述安全字段。
- 模型目录新增 `connectionId?:string`、`aspectRatios?:string[]`；地址、模型名和 Key 在独立表管理。公开连接 ID `environment` 表示现有环境连接，只在确已配置时展示。
- 后端 `ModelConnectionService.snapshot(model:dict|str|None=None)`：异步返回安全快照 `{connectionId,baseUrl,modelName,protocol,modelId?}`。显式模型取已发布模型；无选择的现有入口使用已发布目录的默认首个模型。已有历史 `modelPreset` 可直接解析，保持历史连接。
- `ImageEditRequest.model_connection:dict|None`：可选安全快照，执行器按引用从后端解析凭据。`ConfiguredImageEditor` 的 `describe_request` 和 `edit` 与已有端口兼容；测试中注入的假模型不受影响。

## 验证重点

先编写失败测试，再实现。连接保存后 GET 不泄露 Key；版本 A 与版本 B 的测试请求使用不同地址和 Key，旧快照仍用 A；Base URL 带或不带 `/v1` 都不能重复拼接；错误及日志不得回显凭据；其他工作区连接不可引用。界面测试确认没有模型提示词绑定，留空 Key 保留凭据，连接保存失败不会发布普通配置。

## 交付记录（2026-09-18）

入口：生成配置 → 配置类型选择「生图模型」→ 新增或编辑模型。填写接口地址、实际模型名及 API Key，保存模型后依次「保存草稿」「发布配置」。修改已有连接时 API Key 留空保留；说明为选填，不参与提示词拼接。厂商仅为展示标签，实际连接由独立配置决定。

- 支持 OpenAI 兼容图片接口，地址填写基础地址或以 `/v1` 结尾的地址，不能填写完整的 `/images/edits` 路径。分辨率支持 1K／2K／4K，比例支持 1:1、3:4、4:3、16:9。比例留空表示不额外限制这四种比例。
- 主图／套图使用用户选择的模型。暂没有模型选择器的白底图、图片编辑、提示词测试、统一风格入口使用已发布目录的首个模型；统一风格与编辑 API 也接受已发布模型 ID。提示词测试保留其现有 `size` 参数协议。外部 `modelId` 不允许传入连接对象，以免绕过发布流程。
- 提交时冻结连接版本和模型能力。切换已发布连接不会改变已提交任务；画布历史迭代沿用原连接。完全旧式任务缺少连接引用时兼容原环境配置，不能追溯冻结从未存储的旧凭据。
- 默认 Windows DPAPI 绑定当前 Windows 用户／机器。迁往其他机器须重新填写 Key；若部署使用 `MODEL_CONNECTION_ENCRYPTION_KEY`，必须保存并备份该 Fernet 主密钥。旧 DPAPI 记录不会自动转为 Fernet，切换部署方案应重新保存连接。普通数据库快照不包含明文 Key。
- 数据库迁移已通过正常迁移命令执行至 `e6f7a8b9c0d1`。同步后端健康检查的目标版本，并加入迁移目录 head 一致性测试，没有修改既有迁移文件或手工篡改版本记录。
