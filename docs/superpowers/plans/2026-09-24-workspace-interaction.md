# 工作台交互优化实施计划

**Goal:** 落实已批准的交互清单：画布内嵌、移除参考套图、结果与任务状态分离、缓存与加载反馈、任务中心自动更新及代码拆分。

**Architecture:** 保留现有 React、TanStack Router、Zustand 与 FastAPI。工作台使用项目内标签；结果展示按真实任务/资产关联分组；共享读取层提供短时缓存与在途合并，写操作保持现有幂等和确认行为。复杂交互补行为回归测试。

**Spec:** docs/research/2026-09-24-new-api-interaction-source-notes.md（用户已确认开始）。

## 全局约束

- 在当前用户工作区实现，保留已有后端及 planning-master 未提交修改；不做提交、推送、部署或真实付费生成。
- 不删除历史素材；取消参考套图入口后新请求忽略旧草稿中的参考选择。
- 真实任务状态与当前查看批次分离，不伪造进度或批次关联；刷新不抢占选中图片。
- 子任务只修改分配文件，不启动额外子代理；E2E 统一由主代理运行以避免端口冲突。
