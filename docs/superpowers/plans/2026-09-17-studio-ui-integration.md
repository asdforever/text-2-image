- 中文界面；浅灰白底、深灰文字、墨绿主操作；保留手动深色主题。
- 不改服务端、数据库、计费调用；测试使用 API 边界替身，不请求真实生图。
- 保留白底图、主图、套图、画布、素材、版本及项目删除入口。
- 桌面右侧配置独立滚动；移动端配置抽屉支持关闭、键盘恢复，无横向溢出。
- 原型继续保留为开发预览，正式入口为 `/workspace`。
