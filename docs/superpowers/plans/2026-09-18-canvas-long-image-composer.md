# 画布长图制作实施计划

**目标：** 选取项目图片的固定版本，轻量排版后拼接、保存到成品库并导出。

**架构：** 现有项目资产作为固定版本来源。Pillow 后端拼接，新资产来源快照保存方案；前端独立制作弹窗嵌入画布。无需迁移；排版拼接不调用生图服务，单独确认的选择性风格统一调用生图模型。

**技术栈：** React / TypeScript、FastAPI、Pillow、现有项目资产与幂等仓储。

**规格：** `openspec/changes/canvas-long-image-composer/specs/canvas-long-image-composer/spec.md`；详细接口和限制见同目录 `design.md`。

## 全局约束

界面和文档中文；保留当前工作区其他修改；来源版本不覆盖；宽度 320–1600，1–20 张，单边裁剪 0–45%，间距和留白 0–200；最大高度 30000、3200 万像素；输入单图 2400 万像素、合计 100 MiB；线程池串行渲染。
