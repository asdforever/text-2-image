# 图片编辑器核心工具实施计划

目标：落实本轮确认的添加文本、改文字、局部重绘，合并消除入口，补充裁剪尺寸调整、撤销重做与原图对照。

范围：沿用现有图片编辑会话、任务和成品资产链路；主分支当前工作区继续实施，保留已有修改，不提交付费生图请求。

## 设计与边界

- 编辑工具仅保留添加文本、改文字、局部重绘、裁剪与尺寸。移除再次生成入口，收起扩图；历史旧操作可以移除但不会被静默执行。
- 新操作携带 `payload.schemaVersion = 2`。后端验证区域、笔画、文字和输出尺寸，编译完整指令与选区引导图；模型返回后按遮罩合成，区域外保留原图像素。
- 裁剪与缩放使用 Pillow 确定性处理，单独使用时不依赖生成模型。裁剪放在文字、局部修改之后执行，坐标始终相对于源图。
- 文字编辑保存文本、区域、字号、字体、颜色、对齐及描边参数，草稿可继续调整；生成后参数仍在操作快照中，像素图中的文字不会被误称为独立可编辑图层。
- 改文字允许手工框选，不以 OCR 能力作为可用前提。OCR 未配置时不自动发起识别。
- 浏览器操作先存本地草稿，点击添加或更新修改后保存到会话；所有保存顺序执行，提交等待保存完成并冻结已保存操作，防止输入与提交竞态。
- 生成结果作为新图片资产保留，沿用画布的版本选择和对比，不覆盖输入图片。
