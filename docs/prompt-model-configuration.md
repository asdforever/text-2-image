# 提示词模型配置

打开“生成配置”，在“配置类型”中选择“提示词模型”。这里配置用于风格规划、主图模块规划及详情页模块规划的大语言模型。

1. 点击“新增提示词模型”，填写接口地址、实际模型名和 API Key。接口支持 OpenAI 兼容 Chat Completions，模型需要支持图片输入和 JSON 输出；根地址自动补 `/v1`，也可以填写服务商提供的完整 API 前缀，例如 `/v1` 或 `/api/v3`。
2. 保存连接后，页面会选择该模型。点击顶部“保存草稿”，再点击“发布配置”，后续新任务即可使用。
3. 编辑已有模型时，API Key 留空会保留原密钥。也可以选择已保存的其他提示词模型。
4. 选择“沿用后端配置”并保存发布，可恢复使用服务端 `context_*` 设置。

生图模型继续在“生图模型”栏单独配置。一次规划中的风格与所有模块使用同一模型连接；规划途中发布新配置不会改变正在执行的任务。历史方案继续使用已保存的提示词结果。

API Key 加密存放在独立连接记录中，不出现在普通配置、任务快照或浏览器缓存中。保存连接会创建新版本，避免编辑影响已有任务。

## 部署

应用需要迁移 `a8b9c0d1e2f3`，在既有模型连接表中允许 `openai_chat` 协议，不删除数据。在仓库根目录执行 `python -m backend.cli migrate` 后重启 API。
