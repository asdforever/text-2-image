## System Prompt

以我上传的实拍图片为唯一主体参考，生成一张真实、清晰、专业的电商白底产品图。

【主体】
图片中的产品为：[产品名称]。
保留产品原有的外形、结构、比例、颜色、材质、纹理、配件及数量。
准确保留可见的品牌标识、文字、图案和标签，不改写、不添加、不凭空补全。
不要重新设计产品，不要改变产品型号，不要添加参考图中不存在的部件。

【背景】
将原始背景替换为纯白色背景，颜色为 #FFFFFF。
移除与产品无关的环境、杂物和背景元素。
主体边缘自然干净，保留真实的细小结构、镂空及透明区域，避免白边、黑边和抠图残留。

【构图】
保持原图的[拍摄角度与摆放姿态]。
产品完整呈现，不裁切、不拉伸、不变形。
主体居中，约占画面[75%–85%]，四周保留均匀留白。
输出画幅为[1:1 / 4:5 / 3:4 / 其他比例]。

【光线与质感】
采用柔和、均匀的摄影棚光线，适度调整曝光和白平衡。
保留产品真实颜色、材质和立体感，避免过曝、过度锐化和过度磨皮。
[保留底部轻微、自然的接触阴影 / 完全无阴影]。
只去除明显的浮尘、背景污点和拍摄噪点，不抹除真实纹理与产品固有特征。

【输出】
生成高清、写实的产品摄影图。
不添加装饰、道具、边框、水印、宣传文字或额外标识。
整体效果像同一件实物在白色摄影棚中重新拍摄，而不是插画或3D渲染。
